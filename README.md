# 🚀 Credit Scoring AI API

Questo progetto mappa l'architettura di produzione per il deployment di un modello di Intelligenza Artificiale dedicato alla valutazione del rischio di credito. L'applicazione riceve dati utente in formato JSON e risponde in tempo reale con la decisione di approvazione del prestito.

## 🛠️ Stack Tecnologico
* **Framework API:** FastAPI
* **Server Web:** Uvicorn
* **Data Handling:** Pandas
* **Environment:** Python 3.14+ (macOS asyncio loop config)

## 📦 Installazione e Setup

1. Installa le dipendenze richieste:
```bash
pip3 install -r requirements.txt
```

2. Avvia l'API in locale:
```bash
python3 src/app.py
```

3. Apri il browser all'indirizzo interattivo per testare l'AI:
👉 👉 http://localhost:8080/docs
